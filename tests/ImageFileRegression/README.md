# Регрессии файлов изображений

Из корня репозитория: `dotnet run --project tests/ImageFileRegression --configfile tests/ImageFileRegression/NuGet.Config` (SDK .NET 9).

Проверки подключают два оригинальных метода и функцию хеширования напрямую. Временные файлы изолированы; EF/hosting заменены минимальными заглушками. SQL и реальное приложение не запускаются. Проверяются точный набор файлов, содержимое после переименования и сохранение прежнего обновления метаданных/флага SaveChanges на заглушке. Это не интеграционный тест MySQL.

Случаи: a/ba, реальные alias и alias_N, размер/качество/оба суффикса, соседние оригиналы, неверные суффиксы/расширения, regex-символы в имени и расширении, путь с/без завершающего разделителя, отсутствующий оригинал и отдельные каталоги товаров. Для восстановления внешние NuGet-источники отключены.
