# Регрессии генератора шаблонов

SDK .NET 9, без внешних пакетов. Из корня репозитория:

```powershell
dotnet restore tests/TemplateRegression --configfile tests/TemplateRegression/NuGet.Config
dotnet run --project tests/TemplateRegression --no-restore
```

Подключены оригинальные файлы TemplateRendering, WriteCshtmlContentToFile, GetFileContent и AddChunk/EditChunk/DeleteChunk. HTTP/hosting/EF, преобразование входной модели, уникальность имени и журнал заменены минимальными заглушками; приложение, реальная БД и Razor runtime не запускаются. Файловые операции выполняются в уникальной scratch-папке под каталогом тестовой сборки и очищаются после сценария.

Проверки:

- 8 полных результатов сравниваются с Expected.json, записанным из сохранённой версии генератора **до исправления** на тех же заглушках: пустой ввод, обычные маркеры/экранирование @/счётчики, повторные чанки, skipChunkName, вложенные условия обоих типов, tag helper внутри условия, динамические изображения/список товаров/пагинация. Порядок дополнительных директив также сравнивается.
- Два списка и их изменяемые элементы независимы; создание второго списка не загрязняет первый.
- 200 параллельных рендеров с отдельными контекстами сравниваются с эталоном.
- Реальные операции добавления, переименования и удаления чанка перегенерируют зависимый шаблон, чанк и блок товара. Проверены пути, отдельные замены, дополнительные директивы, отсутствие удалённого/старого файла. При изменении только текста обновляется сам чанк, родители не перегенерируются, как и прежде.
- Заглушка фиксирует поток запуска запросов и пересечение запросов к одному контексту: операции с чанками должны обращаться последовательно в вызывающем потоке.

Expected.json - эталон совместимости, а не ожидаемые исправления всех известных дефектов синтаксиса. Не обновлять его автоматически при падении теста. Служебный режим --record использовался только для получения эталона из исходной версии; проверка EF/MySQL, транзакций и отображения Razor требует отдельной тестовой среды.
