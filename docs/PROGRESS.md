## На этап переноса — не выполнять сейчас

- Выбор совместимых версий EF Core/Npgsql/PostgreSQL, замена провайдера и подключения.
- Сопоставление старой схемы с PostgreSQL: типы/ключи/генерация ID, ограничения, индексы, сравнение строк и регистр; baseline/миграции, перенос данных и сверка результата.
- Проверка переводимости LINQ и семантики поиска на Npgsql; специфическую для MySQL оптимизацию ради конечной архитектуры отдельно оценивать, чтобы не делать двойную работу.
- Последующие предложения с такой зависимостью добавлять сюда отдельно. Критические исправления текущего приложения не откладывать автоматически; необходимость временного решения отмечать явно.
